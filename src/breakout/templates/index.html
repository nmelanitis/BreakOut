First-time setup

Connect your Spotify library

BreakOut needs a Spotify Developer Client ID before it can safely open Spotify’s sign-in page. This takes about two minutes and is needed only once on this computer.

About 2 minutes Read-only access Stored locally
1

Spotify Developer Dashboard

Create your Spotify developer app

  1. Open the Spotify Developer Dashboard and sign in with the Spotify account you want to export.
  2. Select Create app. You can name it BreakOut; the description can be anything helpful to you.
  3. Open the app’s settings and add the Redirect URI below exactly as shown, then save the settings.
  4. Copy the app’s Client ID. Do not copy or enter its Client Secret in BreakOut.
Why this is needed

A Client ID identifies your personal BreakOut integration to Spotify. It is not a password and is safe to store locally.

2

Important

Register this callback address

This application runs locally on your computer and is not exposed through a public web server.

Add the following Redirect URI to your Spotify developer app exactly as displayed:

http://127.0.0.1:3000/auth/spotify/callback

Spotify will use this address to return your browser to the locally running application after you approve access.

Use this address exactly

Do not replace 127.0.0.1 with localhost. Your Spotify password is entered only on Spotify’s website and is never shared with this application.

3

Back in BreakOut

Paste your Client ID

BreakOut stores this public identifier only on this computer. Your Spotify password and access token are never saved.
